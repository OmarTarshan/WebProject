تطبيقات الموبايل (Mobile Application)

يركز هذا المسار على بناء تطبيقات الهواتف الذكية لنظامي Android و iOS، سواء بتطوير كل نظام بشكل منفصل أو باستخدام Flutter لبناء التطبيقين بكود واحد.

أهم اللغات والأدوات

Dart Flutter Kotlin Swift Firebase

خطوات البداية

  1. تعلّم أساسيات البرمجة ولغة Dart مع مفاهيم البرمجة كائنية التوجه (OOP).
  2. التدرب على بناء الشاشات وتصميم الواجهات باستخدام Flutter Widgets.
  3. تعلّم التنقل بين الصفحات وحفظ البيانات وربط التطبيق بالإنترنت.
  4. تنفيذ تطبيق عملي كامل مثل تطبيق للمهام اليومية أو قائمة منتجات.

مصادر مجانية للتعلم

  • Flutter Official Docs — التوثيق الرسمي والدروس العملية لـ Flutter.
  • Android Developers — مسار جوجل المجاني لتطوير تطبيقات أندرويد.
  • freeCodeCamp — دورات مجانية عملية لبناء تطبيقات موبايل كاملة.
