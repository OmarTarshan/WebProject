الأمن السيبراني (Cyber Security)

يركز هذا المسار على حماية الأنظمة والشبكات والبيانات من الهجمات الإلكترونية والاختراق، سواء عبر اكتشاف الثغرات الأمنية وتأمين البنية التحتية أو مراقبة الأنظمة والاستجابة للحوادث السيبرانية.

اللغات والأدوات

Python Linux Bash Wireshark Nmap Burp Suite

خطوات البداية

  1. تعلّم أساسيات الشبكات (Networking) وبروتوكولات الإنترنت مثل TCP/IP و DNS و HTTP.
  2. التدرّب على أنظمة التشغيل وخاصة نظام Linux وأوامر سطر الأوامر (Command Line).
  3. تعلّم أساسيات البرمجة بلغة Python أو Bash لأتمتة المهام وفهم كيفية عمل الثغرات.
  4. التطبيق العملي على منصات التدريب والمختبرات التفاعلية لحل التحديات الأمنية واكتشاف الثغرات.

مصادر التعلم

  • TryHackMe — مسارات تعليمية وتطبيقية تفاعلية للمبتدئين في الأمن السيبراني.
  • Cisco Networking Academy — دورات مجانية معتمدة في أساسيات الشبكات والأمن السيبراني.
  • PortSwigger Web Security Academy — شروحات وتدريبات عملية مجانية على ثغرات تطبيقات الويب.
